# SimpleAnalysis

Учебная программа для практики. Реализация собрана строго под индивидуальное задание: генерация Dataset, объект `Series`, формирование `DataFrame` и сводная информация о нём, очистка данных, расчёт стандартных числовых характеристик, явное разделение по признакам, суммарные показатели по диапазонам, сохранение результатов и три типа визуализации средствами Matplotlib.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

При обычном запуске программа сохраняет PNG-файлы и одновременно показывает графики в окнах Matplotlib.

Для запуска без открытия графических окон:

```bash
python main.py --no-show
```

## Что формирует программа

- `dataset.csv` — 1000 исходных целых чисел;
- `dataframe.csv` — исходные значения, знак, диапазон, значения по возрастанию и по убыванию;
- `ranges.csv` — суммарные показатели по диапазонам (количество, сумма, среднее, минимум, максимум);
- `combined_dataframe.csv` — объединённая структура: исходное значение, округление до сотен, абсолютное значение, знак, диапазон;
- `result.txt` — сводка DataFrame, статистики, разделение по признакам и расчёты по диапазонам;
- `linear_plot.png` — линейный график исходного набора;
- `histogram.png` — гистограмма значений после округления до сотен;
- `sorted_values.png` — совместный график значений по возрастанию и убыванию;
- `combined_dependence.png` — зависимости по объединённым показателям.

Используется `random.seed(42)`, поэтому результаты воспроизводимы и совпадают с числами, приведенными в отчете: минимум `-9987`, максимум `9999`, сумма `172397`, повторяющихся элементов `23`, среднеквадратическое отклонение `5754.15`.
